# Capturas para App Store y Google Play

Genera desde http://localhost:8084 con la app en ejecución.

## Mínimo requerido

| Plataforma | Cantidad | Resolución sugerida |
|------------|----------|---------------------|
| Android | 2+ | 1080×1920 o similar |
| iPhone | 3+ | 1290×2796 (6.7") |

## Pantallas recomendadas

1. Explorar / Feed
2. Rutas
3. Clubes
4. Perfil / login

## Cómo capturar

1. `npm run dev:api` + `npm run dev:web`
2. Abre http://localhost:8084
3. Captura con Win+Shift+S o herramienta del navegador
4. Guarda aquí como `android-01-feed.png`, `ios-01-feed.png`, etc.
